# Brand reference — REFERENCE ONLY — NOT PRODUCTION LOGO ASSET

`core-orbital-concept-REFERENCE-ONLY.webp` is the owner-approved concept board for the
PDA BLISS CORE identity (EP24.1.3): a luminous CORE sphere, orbital rings, connected nodes,
premium silver and a teal-lit centre on a dark enterprise ground.

It is kept here **only** as the design reference the production marks were drawn from.

- Do **not** use it in the product UI, on the website, in documents sent to customers, or as
  a favicon / app icon / social image.
- Do **not** trace, crop or export logos from it.
- The production assets are vector files generated from
  `frontend/src/components/brand/geometry.ts` into `frontend/public/brand/` — see
  [`docs/BRAND_IDENTITY.md`](../../BRAND_IDENTITY.md).
